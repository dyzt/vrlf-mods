Hides every player's in-game crosshair in Halo: Fireteam Raven, for VR play
with VRLF, where you aim with the gun itself. Covers the assault rifle and
every pickup and vehicle weapon, in every cabinet type.

The game uses the assault rifle crosshair for its game select, name entry and
gun calibration pointers too, so those go as well. Point with VRLF's laser
there instead.

Install
1. Close the game and TeknoParrot.
2. Back up your game's data\g7\2dcommon.g7.
3. Copy the data folder from this zip into your Halo game folder (the folder
   that holds "game", "halo.so" and "data", usually pm\g7\halo) and
   overwrite when asked.
4. In TeknoParrot's Game Settings for Halo, turn on
   BypassFilesystemIntegrityTest, so the game's file check does not flag the
   change.

Undo
Put your backed-up 2dcommon.g7 back.
