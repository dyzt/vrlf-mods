# rambo: Rambo: The Video Game VRLF Mod

- **Game:** Rambo The Video Game (Steam app **274130**, Teyon, 2014). Not the Sega
  Lindbergh arcade Rambo.
- **Type:** standalone `dinput8.dll` proxy + `rambo_vrlf.cfg`, in the game root.
- **Registry version:** `1.0.0`
- **Distribution zip:** `dist/rambo-v1.0.0.zip` (from release `v1.0.0` of the private
  `dyzt/rambo-vrlf-mod`; extracts into the game root).
- **Profile:** `aim_mode: "bus"` with two virtual pads; both players need ViGEmBus, solo
  included.
