# freakhunter: FREAKHUNTER VRLF Mod

- **Game:** FREAKHUNTER (Steam app **2773870**)
- **Type:** BepInEx 5 (Mono), bundled inside the zip (winhttp.dll + doorstop + BepInEx tree)
- **Registry version:** `1.1.2`
- **Distribution zip:** `dist/freakhunter-v1.1.2.zip`
- **Source (private):** `dyzt/freakhunter-vrlf-mod`

Puts the game's reticle on the mouse cursor, so any absolute light gun aims 1:1 (VRLF, Sinden, GunCon). Maps onto the game's 4:3 picture, so fullscreen (pillarboxed) and windowed both line up.
